Designed & Developed by Areeba Imran  
© 2026 Areeba Imran. All rights reserved.

An expert RAG-based assistant built to answer queries regarding PTCL packages using a document knowledge base, featuring multilingual support, speech recognition, and audio synthesis.

## Run Locally
1. `pip install -r requirements.txt`
2. Place PTCL documents in `knowledge_base/`
3. `python scripts/build_knowledge_base.py`
4. `streamlit run app.py`
